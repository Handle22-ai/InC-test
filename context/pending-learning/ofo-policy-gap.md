# OFO policy gap — unapproved proposal

Status: observed gap / proposed clarification. This is not a new classifier rule
or permission to change the canonical contract.

The inherited scorer groups OFO with force majeure in a confidence feature.

classifier considers the approved source-fact predicates; notice type alone
does not create a candidate. An OFO whose operational assertions are unknown
remains unresolved under the existing fallback. A restriction asserted in an
OFO is judged by the same approved predicates, not by a new blanket OFO rule.

Owner decision needed: specify which source-grounded OFO directions, obligations,
restrictions and effective intervals should produce an assessment proposal,
which cases require review, and which independent witnesses support that scope.
