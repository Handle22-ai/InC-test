# FRESH_SESSION_TASK.md — Fresh Agent Maintenance Exercise

You are entering this repository with **no access to previous agent conversations**.

Use only:
- repository;
- persisted context;
- harness;
- this maintenance request.

## Maintenance request

Use a prepared small source-format or behavior change affecting the rebuilt component.

A good example:

> Support one supplied new-format NGPL notice while preserving all previously specified behavior.

## Required procedure

1. Read repository instructions.
2. Invoke/use harness context selection.
3. Record selected:
   - requirements;
   - source scope;
   - decisions;
   - assumptions;
   - failures;
   - regressions;
   - gates.
4. Inspect only necessary source.
5. Implement change.
6. Run applicable gates.
7. Run regression comparison.
8. Record extra human explanation, if any.
9. Persist new failure/regression/learning.
10. Do not silently change requirements.
11. Update `evidence/fresh_session.md`.
